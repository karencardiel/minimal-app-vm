# ![Computer with a face](https://emojis.slackmojis.com/emojis/images/1643515453/14740/pc_computer.gif?1643515453) Class activity: 1st Dash viz 

This activity includes four visualizations for point-of-sale data: orders, payments, sessions, and Sales by Month, Week and Responsible Person. It uses Python and Plotly to display interactive visualizations, with a PostgreSQL connection to retrieve data from SQL tables.
